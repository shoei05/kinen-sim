# 禁煙外来シミュレーター

禁煙外来の初診場面で、医師として返答を7回選びます。架空の患者「ネコタ・タマさん」が、選んだ返答に応じて音声で答えます。台詞の上には、そのときの表情やしぐさが表示されます。

- 公開ページ: https://shoei05.github.io/kinen-sim/
- 返答ごとに、◎（面接の原則に沿った返答）、△（内容は正しいが伝え方を見直したい返答）、✕（内容の訂正が必要な返答）の区分と解説が出ます。
- 最後に、7場面中の◎の数と、場面ごとの振り返りが出ます。同じ返答を選べば、何回やっても同じ結果になります。
- 台詞と解説の根拠にした資料は [SOURCES.md](SOURCES.md) にあります。
